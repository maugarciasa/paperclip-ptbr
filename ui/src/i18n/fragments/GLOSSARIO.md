Regras:
- Nomes de produtos e fornecedores ficam como estão (Claude, Codex, OpenAI, GitHub, Paperclip).
- Não traduza nomes de comandos, variáveis de ambiente, URLs, caminhos e chaves de API.
- Mantenha os placeholders `{{nome}}` exatamente como no inglês.
- Não coloque HTML no texto. Quebre em duas chaves se precisar de link ou negrito.
- Use "você" no tom neutro; evite "tu".
- Escreva com acentos corretos (ç, ã, é, ê, ó, etc.).
